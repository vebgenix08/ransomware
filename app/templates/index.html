Project roadmap

Building RansomShield one validated layer at a time.

Status reflects the current local implementation. Synthetic results do not establish real-world detection performance.

Next research milestoneCollect independently labeled endpoint telemetry and validate the live rules against benign and ransomware activity. Current live alerts are not malware verdicts.
Phase 01Completed

Research and system design

Define the problem, related work, behavioral signals, and hybrid architecture.

02
Phase 02Completed

Flask application and accounts

Authentication, live dashboard, run history, incident details and downloadable CSV reports are implemented and locally tested.

03
Phase 03Research prototype

Behavior model and response audit

The telemetry model was trained on synthetic sequences. It is experimental and has not been validated on live endpoint ransomware behavior.

04
Phase 04Completed locally

Published dataset integration

Published MLRan CSV integrated with a separately trained XGBoost model: 2,300 training and 324 held-out samples. Results apply to this dataset only.

05
Phase 05In progress

Independent endpoint validation

The remaining research milestone is testing live monitoring against independently labeled endpoint activity and measuring false positives and missed events.
