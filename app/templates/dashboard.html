Beginner guide

How to use RansomShield

For a safe test, use a disposable folder and files you can change.

  1. Open Monitor files and select a folder.
  2. Create, edit, or delete a test file; wait up to five seconds.
  3. Review the action and path under Recent activity, then stop monitoring.

SILRAD is a separate offline dataset test. A live activity alert asks for review; it does not confirm ransomware or quarantine files.

SILRAD held-out benchmark

This offline benchmark evaluates SILRAD’s published, labeled Sysmon events with an incremental Adaptive Random Forest. It predicts each test event before learning that row’s known label for the next event. The benchmark does not power live folder alerts.

Downloading published benchmark data and training the model on the server. This can take a few minutes.

About this benchmark

Select Prepare SILRAD data to download the published dataset from its source repository. Threshold selection uses training data only. The test predicts each row before using its known dataset label to update the next prediction. This is a labeled offline experiment, not proof of live endpoint detection. Raw event text is not stored in run reports.

For local setup, run .venv\Scripts\python.exe scripts\setup_silrad.py from the project folder.

On a hosted service without persistent storage, prepare the dataset again if a redeploy removes local files.
