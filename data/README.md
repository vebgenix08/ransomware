# Safe datasets

Published MLRan is now included in `mlran/`: original feature CSVs, a cleaned
held-out CSV, training report and attribution. The application selects its
separately trained XGBoost model automatically. See `mlran/README.md`.

`safe_demo.csv` is generated by `scripts/prepare_demo_csv.py`. It contains 16
synthetic windows from two independent traces (8 benign and 8 suspicious).
Use it to demonstrate CSV transfer, validation, inference, metrics, and response.
Its metrics are functional checks, **not published-dataset performance**.

`rande_w11_preview.csv` is an unmodified public preview downloaded on 2026-10-14.

The preview contains whole-sample behavioral features and labels, not this
detector's ordered two-second windows. The importer intentionally rejects it.
`fs_modified_file_count` cannot be renamed to `modified_count` without changing
the measurement meaning; CPU, memory, canary state and ordered windows are absent.
No missing values are invented. Downloading this preview does not complete model
integration, training, or external validation.

To complete published-data integration, obtain compatible timestamped source
telemetry with all required measurements, or design and train a separate model
for the published feature schema. A static feature vector is not a time sequence.
The full RanDe-W11 dataset is available upon request according to its repository;
this project includes only the public preview. No executable samples are included.
